# EZ华文 · 小学华文复习

Revision site for Primary 1–6 Chinese (《欢乐伙伴》word lists): recognising and writing characters, reading comprehension, and grammar (from 三上).

- Keep all files in the same place. Open `index.html` in a browser, or publish with GitHub Pages.
- Progress is saved in each student's own browser. Students can copy a progress code from 我的进度.
- All names in the passages are made up.
